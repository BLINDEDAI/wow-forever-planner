# WoW Forever planner

Planificador de talentos y guía de subida de nivel para un Priest en WoW Forever. Todo funciona en el navegador:
los builds y las notas se guardan en `localStorage` y se comparten con un enlace.

```
npm install
npm run dev
```

Datos de la beta, sujetos a cambios. Se actualizan con `npm run sync:talents`, `npm run sync:spells` y `npm run sync:gear`.

## Créditos

- Talentos, textos, equipo e iconos: [ForeverDB](https://foreverdb.net).
- Raciales y hechizos de entrenador: [talentsforever.com](https://talentsforever.com) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).
- Opiniones de las guías en vídeo de AwesomeSP y Toleduck.

Proyecto de fan, sin relación con Blizzard Entertainment.
